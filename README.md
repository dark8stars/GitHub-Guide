# Git & GitHub Guide

## 📌 Project Overview
This repository is a collaborative university project designed to practice and demonstrate fundamental version control workflows using Git and GitHub. The main objective of this project is to learn how multiple developers can work simultaneously on a shared codebase, manage branches, handle merge conflicts, perform code reviews, and utilize issues and pull requests effectively.
